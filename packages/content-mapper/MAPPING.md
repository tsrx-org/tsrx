# Mapping inventory

Inventory of every mapping site in the shared type-only transform
(`packages/tsrx/src/transform/segments.js`), grouped by the `mapping_data` variant
it uses (`packages/tsrx/src/source-map-utils.js`), with the content-mapper span
kind each one becomes. Taken on 2026-09-18 for Phase 0 of
https://github.com/tsrx-org/tsrx/issues/41.

## Feature bit assignment per variant

| Variant                                    | Flags                                                                       | Span features                                                                                                                                                                                                                                                      |
| ------------------------------------------ | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `mapping_data`                             | verification, completion, semantic, navigation, structure                   | Hover, SignatureHelp, InlayHints, SemanticTokens, Completion, AutoInsert, Definition, TypeDefinition, Implementation, References, DocumentHighlights, Rename, CallHierarchy, CodeActions, LinkedEditing, FoldingRanges, SelectionRanges, DocumentSymbols, CodeLens |
| `mapping_data_verify_only`                 | verification                                                                | none (diagnostics always apply)                                                                                                                                                                                                                                    |
| `mapping_data_verify_complete`             | verification, completion                                                    | Completion, AutoInsert                                                                                                                                                                                                                                             |
| `mapping_data_completion_only`             | completion                                                                  | Completion, AutoInsert                                                                                                                                                                                                                                             |
| `mapping_data_string_span`                 | as `mapping_data` minus completion; `semantic.shouldHighlight()` is `false` | as `mapping_data` minus Completion, AutoInsert, SemanticTokens                                                                                                                                                                                                     |
| `{ ...mapping_data, verification: false }` | all but verification                                                        | as `mapping_data`                                                                                                                                                                                                                                                  |

`verification` has no feature bit in the protocol: diagnostics apply to every
span. Formatting is never enabled (`format: false` everywhere).

## Sites

Length column: whether the generated span length equals the source span length.
`equal` sites become `Verbatim` when the text is identical, otherwise `Atom`.
`may differ` sites are `Atom`, except obfuscated identifiers which are `Alias` so
diagnostic text shows the authored name.

| Site (segments.js)                                                       | Variant                                                                                                                                                                         | Length                           | Notes                                                                                                                                                                                                     |
| ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

## `customData` consumers

- `hover` and `definition`: CSS class spans, consumed by the TSRX language server
  (`hoverPlugin.js`, `definitionPlugin.js`). Not TypeScript's concern.
- `wordHighlight`: keyword highlights (`documentHighlightPlugin.js`).
- `suppressedDiagnostics`: removed in Phase 0. No transform ever produced it.

## Post-processing in `span-mappings.js`

- Container spans lose to the token spans they enclose (Verbatim first, then
  shorter before longer, disjoint in generated space).
- Neighbouring Verbatim spans with equal feature bits whose gap is identical text
  in both files are coalesced, so whole statements such as import declarations
  become one edit-safe span.
- Atom candidates that are fragments of an identifier (the one-character
  file-start anchor) are dropped.
